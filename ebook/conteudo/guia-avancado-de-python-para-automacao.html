🧭 Introdução: A Filosofia da Automação Profissional

Automatizar com excelência não significa apenas criar um script de 20 linhas que roda no seu computador pessoal e quebra no dia seguinte. Automação profissional exige:

  • Idempotência: A capacidade de executar a mesma rotina múltiplas vezes sem duplicar registros ou corromper dados.
  • Resiliência: Quedas de conexão e timeouts devem ser tolerados com tentativas automáticas e espaçamento crescente (Exponential Backoff).
  • Observabilidade: Logs claros e estruturados que revelam exatamente o que o robô fez a cada segundo.

🚀 Capítulo 1: Automação Web Moderna com Playwright Assíncrono

O Selenium foi o pioneiro, mas o Playwright tornou-se a escolha moderna devido ao suporte nativo a operações assíncronas, controle granular de múltiplos contextos e velocidade até 4x superior.

import asyncio
from playwright.async_api import async_playwright

async def run_automation():
    async with async_playwright() as p:
        browser = await p.chromium.launch(
            headless=True,
            args=["--disable-blink-features=AutomationControlled"]
        )
        context = await browser.new_context(
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...",
            viewport={"width": 1920, "height": 1080}
        )
        page = await context.new_page()
        
        await page.goto("https://painel.empresa.com", wait_until="networkidle")
        await page.fill("#usuario", "operador_sistema")
        await page.fill("#senha", "ChaveSegura2026!")
        await page.click("button[type='submit']")
        
        await page.wait_for_url("**/dashboard")
        await page.screenshot(path="dashboard_auditoria.png", full_page=True)
        
        await context.close()
        await browser.close()

if __name__ == "__main__":
    asyncio.run(run_automation())

⚙️ Concorrência com Semáforos

Um semáforo limita a quantidade máxima de requisições ativas simultaneamente (ex: 20 conexões simultâneas), permitindo disparar 5.000 requisições sem estourar o limite de conexões do servidor ou a memória RAM.

📋 Checklist: Os 5 Mandamentos da Automação Blindada

  • [ ] Gestão de Segredos: Nenhuma senha ou chave de API salva diretamente no código fonte; uso obrigatório de .env.
  • [ ] Timeouts Explícitos: Nenhuma chamada de rede ou busca de seletor web sem tempo limite definido.
  • [ ] Mecanismo de Retry: Tratamento automático com backoff exponencial para falhas temporárias de conexão.
  • [ ] Logs Rotativos: Gravação de logs com limite máximo de tamanho de arquivo.
  • [ ] Isolamento com Containers: Execução encapsulada em imagens Docker para evitar divergências de ambiente entre desenvolvimento e produção.
